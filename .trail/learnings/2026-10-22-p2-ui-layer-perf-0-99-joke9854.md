## Decided
- User chose to fold P1 into the 0.99.74 release: no separate 0.99.73 [release] commit.
- AppUiState.allMedia is a lazy(PUBLICATION) property and findMedia uses a lazy stableKey map; both are per immutable state instance.
- Animated values move to layout/draw: ui/components/DeferredModifiers.kt has fillMaxWidthOf/heightOf/horizontalPaddingOf (lambda versions mirroring the stock modifiers' rounding/constraints); background(animatedColor) after clip becomes drawBehind { drawRect(c) }; scale -> graphicsLayer; offset(dp) -> offset { IntOffset }; if (anim > 0) branches use derivedStateOf.
- LocalDetailAccent now carries State<Color?> (staticCompositionLocalOf); rememberPosterAccent returns a State so the 500 ms fade doesn't recompose DetailScreen. Accent getters read `.current?.value`.
- Skeletons share one pulse per SkeletonPulseGroup (fraction 0..1 + lerp of each skeleton's own range/duration); groups take `enabled` so no infinite animation runs once loaded.
- SharedHttp.client is the one pool; every client (TMDB/Simkl/Floppy/Floppy OAuth/Coil) derives via newBuilder(). Floppy keeps its explicit timeouts and followRedirects(false).
- TMDB-only HTTP cache, with a network interceptor rewriting Cache-Control to no-cache so every use revalidates: no stale metadata. Simkl/Floppy never cached (sync data).
- Error log is appended; compacts to the last 500 lines once the file exceeds 1000.
- Preview build gets the release baseline profile via sourceSets["preview"].baselineProfiles.srcDir (not regenerated).
## Tried and ruled out
- Replacing animated border(...) alphas (GlassModifiers glow, MediaPoster edge) with drawOutline: stroke inset differs from border, risk of a visible change; left alone.
- Text colour animations need composition; left alone.
## Watch out
- trail check's conflicts on beta-testing come from README/CHANGELOG/issue templates in the branch-vs-main diff, not from code changes.
- Blurred backdrops (Detail hero, Episode detail) decode at 480px via rememberBlurredArtRequest; don't reuse that request for unblurred art.
